# 一键启动简洁界面

2026-11-14。最初调整上位机的操作界面、后台记录及对应回归；后续模拟恢复联动的上下位机修改见[模拟启动与恢复修复说明](模拟启动与恢复修复说明.md)。

默认页面保留三个运动组的选择、各组简短状态、一键启动、停止所选组和停止系统。系统未启动时，一键启动沿用管理启动和端点校验流程；系统已就绪时，同一按钮启动所选运动组，不再重复启动软件。连接设置收进独立窗口；换档、恢复、提交选择及显式复位收进“更多控制”。原有归中、授权、急停和未知结果门槛继续由生产会话层检查。

连接设置的“运动预设”提供底盘组、机械臂组（含夹爪）、全车组、底盘和摆臂组四种组合。选择预设只同步启动页的勾选，不自动连接或启动；手动勾选也会同步预设名称，其他组合显示“自定义选择”。运行环境继续使用管理服务提供的模拟/实机档案。“更多控制”默认窗口为 560×520，支持缩放，并在内容较多或字体放大时提供滚动区域。

页面不再显示 JSON、任务 ID、构建号、能力列表、服务调用结果和滚动日志。对应详细记录自动保存到本机：

```text
~/.local/share/hostcomputer/logs/runtime/runtime.jsonl
~/.local/share/hostcomputer/logs/runtime/latest.json
```

实际路径使用 Qt AppLocalDataLocation，连接设置窗口可查看完整路径；可通过 `HOSTCOMPUTER_RUNTIME_LOG_DIR` 指定其他目录。

- `runtime.jsonl`：带时间的连接、操作、管理错误、服务端日志和控制事件。语义不变的状态不反复追加；每份约 5 MiB，最多保留当前文件和 4 份历史文件。
- `latest.json`：每秒原子更新的管理与控制状态快照，含完整状态、诊断、预设和操作记录。窗口关闭时写入 `page_open:false`，表明这是历史观测，不能据此推断当前机器状态。

两类文件自动隐藏管理令牌、会话信息和 URL 凭据，文件权限为仅当前用户可读写。日志目录不可写时，页面保留简短提示，避免记录失败被忽略。

修改集中在 `RuntimeManagementWidget.{h,cpp}`、新增 `RuntimeJournal.{h,cpp}`、`mainwindow.{h,cpp}` 及构建/测试入口。日志持久化、重开、脱敏、轮转、磁盘错误，以及界面默认隐藏详细信息、配置预填、冷启动/已运行启动、停止和维护门槛均有回归覆盖。

更新后的程序仍通过原入口运行：

```bash
bash /home/fire/hostcomputer/scripts/run_linked.sh
```
