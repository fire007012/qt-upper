## 第五批：控制v2、状态仓库与诊断

下位机参考文档40/41系列 `robot24-p0-config-2`；Qt标识 `host-ros2-v2-config-1`。本轮只读加载真实HostBridgeServer/ControlV2并注入无设备输出，不修改参考实现或通过假报文降低服务端约束。使用流程见[Qt控制v2与诊断](Qt控制v2与诊断使用.md)，兼容声明见[compatibility.json](../deploy/compatibility.json)。下文第四批及更早批次为当时状态，其中“控制v2尚未接入”等表述已由本批更新。

- 新增无socket依赖的ControlSession与ControlProtocol，按身份/六项能力协商session与epoch，100ms刷新token并扣除RTT，200ms查询实际状态。过期输入不补token，重新采样；物理中立与合成零分开，旧服务/模式/速度边沿从连续输入中过滤。
- 管理服务透传端点版本及robot_id；生产管理/手动入口均明确使用v2，不向旧控制运动协议降级。旧v1仅用于心跳、同步、相机和遥测观测，旧ACK/状态不能改变v2授权。未纳入契约的原始电机/关节/笛卡尔写入口拒绝发送。
- 状态栏增加“允许操作”和“允许遥控”、实际许可及桥接急停。两类授权分别明确请求；epoch、token/状态失效、急停、输入拒收及结果未知撤权。撤权代次隔离迟到授权响应；焦点离开及暂停重建未授权会话，待确认授权同样失效。仍按住的键等待实际释放，清理不能伪造中立。
- 长任务先持久记录原ID/命令/参数，再发送并查询operation；accepted/running不当成功。已知ID自动查询，接受未知仅允许明确确认后原ID恢复；不自动重放init/enable。迟到接受也标记未知落盘，unknown/invalidated不产生业务效果或恢复授权。未知结果未核对前阻止新业务操作（停止类仍受各自许可路径约束）。最多32个协议请求、16个执行操作和64条恢复记录；损坏记录保留证据并阻止新业务操作。
- EmergencyChannel使用独立有界短连接和2秒响应时限，普通连接断开后仍可尝试；明确区分桥接软件锁存与physical_stop_confirmed=false，不显示硬件已停。
- 新增RobotStateStore：遥测独立TTL、断线失效、最多32个topic、256条事件和512个RTT样本。CO₂/关节/姿态显示过期，保留最后姿态并显式提示。诊断页提供任务查询/原ID恢复和原子JSON导出，脱敏token/session/密码及URL认证信息，拒绝参考目录输出。
- 新增无GUI的 `--version`、兼容清单与 `check_host_release.py`；核对本机构建标识/Qt6、动态库、FFmpeg并记录SHA256，不自动部署或将本机检查当干净机器验收。

以下“已实现/验证”描述第一批结果，其中Qt6缺失等环境结论已由上述第二批更新；不代表当前环境仍缺Qt6。

## 已实现

- 修复首次连接失败不进入重试的问题；取消重试次数上限，采用约 3s、6s、最多 10s 的退避及少量抖动，连接尝试时限 10s。
- 首次及运行中有效心跳 ACK 超过 3s 时主动重建连接；只匹配当前连接待处理序号，服务端单向 heartbeat 不作为双向在线证明。
- 客户端内部心跳、RTT 和命令 ACK 时限改用单调时间；线上时间戳仍为 Unix 毫秒。
- 每次尝试使用新的 socket，过滤旧 socket 回调；清除接收半帧、旧心跳和命令 ACK，不重放旧命令。主动断开在离线、连接中、等待重试时同样生效，Controller 也会取消离线重试。
- 显示连接、同步、通信就绪和重连状态；对应状态快照必须匹配同步请求序号并包含布尔急停状态。
- 新增“允许遥控/暂停遥控”：连接后默认暂停，需有效心跳、同步完成、急停解除及最近 300ms 内的中立输入才能显式授权。未授权时发送中立快照，其他运动命令也受约束。
- 断线、急停、停止/恢复类生命周期操作、watchdog 或输入拒收撤销授权；恢复通信或解除急停不自动重新授权。此本地授权不替代下位机运行许可。
- 限制发送积压和待处理关键 ACK 数；ACK 类型不匹配不消耗请求，超时不自动重试。ACK 表满时仍优先发送急停，移出跟踪的操作结果标记为不确定。
- 显示输入拒收原因的状态变化，避免每个高频输入重复刷日志；显式不兼容协议版本关闭连接并撤销授权。
- 添加独立通信测试工程、操作说明及仓库 `AGENTS.md` 只读边界约束。
