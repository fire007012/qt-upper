## 已修复的问题

- 发布当前 arm_control、Servo 就绪节点及 MoveIt 启动文件，消除旧安装与源码不一致。六轴反馈独立校验，保持静止起点保护。
- MoveIt 和 Servo 使用过滤后的模型状态，避免其他组故障产生的非有限数值进入碰撞检测；实测机械臂状态仍来自原始反馈。
- Servo 在进程内只启动一次，后续会话使用暂停/恢复。跨 epoch 排空旧 RPC，拒绝旧输入，模式成功需实际收到新鲜零速输出，避免重复创建线程导致延迟与退出崩溃。
- 管理健康检查刷新控制器读回，并给出缺少的控制器/服务。只读 RPC 可在原期限内重试，使能和运动操作不自动重放。
- 默认使用 Cyclone DDS，并随包提供本机发现配置和目标机依赖安装项；处理 Fast DDS 服务回复失败导致控制器管理进程退出的问题。最终回归使用发布中的 DDS 配置，正式安装复核首次遥控位移约 0.096 秒。
- 不可读的运行诊断不再宣称状态新鲜，避免上位机协议误判断开；上位机同步超时从本轮同步开始计时，保留独立的控制租约超时和重新授权要求。
