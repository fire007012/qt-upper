# 视觉监测管理接口要求

2026-11-12。当前控制 v2 的允许命令不包含 `thermal_monitor/dynamic_monitor/danger_sign/qr_code_detect/reset_monitor`。上位机对应按钮已禁用并标明原因；视频查看继续使用原接口，不伪造命令已提交或检测成功。

如需启用，由下位机开发端在独立获授权工作区确定并实现以下契约：

- 明确检测服务属于控制桥还是独立管理服务，定义能力声明、版本、认证/权限和连接发现。未协商对应能力的上位机保持入口禁用。
- 固定允许的检测项、启动/停止/重置语义、参数 schema、请求幂等规则及 request_id/operation_id 查询方式；不提供任意 ROS 服务名执行入口。
- 返回实际检测运行状态和结果的新鲜度、不可用原因、失败/超时/结果未知，以及检测重启/控制桥重启后的恢复行为。
- 检测操作不隐式取得运动控制权、不解除急停、不自动改变运动预设、控制模式或遥控授权。耗时检测不阻塞心跳与输入 watchdog。

当前仓库仅提供上位机不可用提示及接口要求，不修改下位机参考目录。检测功能本身等待该契约与上下位机联调，不算本轮已实现能力。
