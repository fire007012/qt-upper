## 启动与停止

下位机终端启动独立管理器：

```bash
bash /home/fire/ros2_ws_car/linked-runtime/run_manager.sh
```

图形桌面终端启动上位机：

```bash
bash /home/fire/hostcomputer/scripts/run_linked.sh
```

在上位机打开运行管理页，配置已预填，明确点击连接。选择 Mock 档案并执行预检；“启动系统及所选预设”会按界面说明启动软件并顺序操作预设。运动行为由原有中立采样、状态、诊断及明确授权约束。当前配置为本机 `127.0.0.1:9091` 管理、`127.0.0.1:9090` 控制；管理器和下位机节点在 DDS 域 97。

退出前先点击停止系统，等待软件 stopped、停止操作 succeeded 后再关闭管理器；不要把关闭管理器窗口当作机器人停止。也可用原有客户端发送明确 stop，再查询 operation/snapshot：

```bash
python3 -B /home/fire/ros2_ws_car/src/robot_manager/client.py \
  --token-file /home/fire/ros2_ws_car/linked-runtime/manager.token stop
python3 -B /home/fire/ros2_ws_car/src/robot_manager/client.py \
  --token-file /home/fire/ros2_ws_car/linked-runtime/manager.token snapshot
```

此配置仅运行 Mock，没有视频源，不接触真实 CAN。跨机器部署需将 manager 的 bind/bridge_bind、公布的 control_endpoint.host、视频 rtsp.public_host 改为现场可访问的地址，正式硬件档案另行使用真实 commissioning；详见 [联动排查](上下位机联动排查与启动.md)。不要删除控制 journal 来清除急停或规避未知结果。
