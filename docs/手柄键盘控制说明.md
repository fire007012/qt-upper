# 手柄与键盘控制说明文档

## 概述

上位机v2 支持 **键盘** 和 **手柄（SDL3 Gamepad，Windows 下保留 XInput fallback）** 两种输入源。上位机只采集输入快照并转发给下位机，不在本地解析车体/机械臂运动语意。

- 键盘输入以 `keyboard.pressed_keys` 发送。
- 手柄输入以 `gamepad.buttons` 和 `gamepad.axes` 发送。
- 当前上位机只保留急停语意：键盘 `Space`，或手柄 `L3+R3` 同时按下。
- 连续运动语意由下位机解释；模式、服务及速度切换边沿从v2连续输入中过滤，离散操作使用界面业务按钮。

当前生产使用控制v2：session/epoch/freshness及两级授权见[控制与诊断指南](Qt控制v2与诊断使用.md)。不在连续输入中携带旧mode切换字段。

### 连接与遥控授权

每次连接（包括自动重连）后默认暂停遥控。状态栏区分“连接中、控制v2协商、状态同步中、通信已就绪、等待重连”；通信就绪不表示硬件已允许运动。

先中立并明确“允许操作”后提交生命周期及模式任务。运动操作前确认心跳正常、实际运行许可已确认、状态同步完成、急停已解除，释放所有键盘和手柄按钮，将摇杆与扳机归中，再点击状态栏的“允许遥控”。授权只接受最近250ms内采集且已获确认的中立输入；手柄轴中立范围为绝对值不超过 0.04。

暂停期间客户端发送中立快照，运动按钮和运动命令入口不会绕过授权。点击“暂停遥控”、应用失去活动焦点、断线、epoch变化、令牌/状态过期、急停、停止/恢复类生命周期操作、输入 watchdog 或命令被桥接拒收时都会撤销授权；重新连接或解除急停不会自动重新授权。下位机的初始化、使能及运行许可仍需按其流程操作。

“允许遥控”不影响急停入口；急停仍可在未授权遥控时发送。控制输入日志会显示 `STALE_TOKEN`、`EPOCH`、`RUNTIME_PERMISSION` 等v2拒收原因，便于定位“TCP 连着但不能控制”的问题。

| 模式 | 说明 |
|------|------|
| **车体模式** | 控制底盘运动（前后/转向） |
| **机械臂模式** | 控制机械臂末端位姿（笛卡尔空间） |

## 一、键盘输入

> 类：`KeyboardController`，发送频率 10Hz

### 1.1 转发按键

| 按键 | 功能 | 说明 |
|------|------|------|
| 连续字母键 | 转发白名单 | `w a s d u o q e k i j l f h y` |
| 数字、方向、修饰键及其他字母 | 不作为v2连续输入发送 | 仍参与本机物理中立检查，不借按键边沿隐式发起服务或切模式 |
| `Space` | **急停** | 独立连接发送 `emergency_stop` |

暂停时的合成零输入不能证明物理中立。清理时仍按住的键需收到释放事件；丢失释放事件时，回到应用后重新按下并释放该键。

---

## 二、手柄输入

> 类：`HandleKey`（SDL3 Gamepad API，Windows 下可回退到 XInput），轮询频率 50Hz

界面显示全部物理输入，控制v2发送连续输入白名单。上位机不把D-Pad模式切换作为隐式服务，也不把A键解释为急停。

| 输入 | 上位机行为 |
|------|------------|
| A/B/X/Y、LB/RB、D-Pad上/下 | 转发连续按钮快照 |
| Start/Back、D-Pad左/右 | 从v2连续帧过滤，仍用于物理中立检查 |
| L3/R3 | 不发连续帧；同时按下时触发急停 |
| 左右摇杆 | 转发归一化轴值 `[-1.0, 1.0]` |
| LT/RT | 转发归一化轴值 `[0.0, 1.0]` |

## 三、急停机制

急停是最高优先级操作，**不受控制模式和启用状态影响**：

| 触发方式 | 说明 |
|---------|------|
| 键盘 `Space` | 全局快捷键，任何时候可用 |
| 手柄 `L3+R3` | 两个摇杆同时按下 |
| UI「急停」按钮 | 界面按钮 |

急停触发后执行以下操作：

1. 通过独立短TCP连接发送 `emergency_stop`，不依赖普通会话或令牌
2. 清空本地输入快照
3. 保留仍按住键的释放等待，撤销两类授权

桥接ACK只确认软件急停锁存与发起停止，不证明设备物理停止。普通连接断开后有目标地址时仍可尝试独立急停。

## 四、数据流

```
┌──────────────────────┐
│  键盘按键 / 手柄摇杆  │   ← 用户输入
└──────────┬───────────┘
           │
           ▼
┌──────────────────────┐
│  KeyboardController  │   ← 10Hz 定时发送
│  HandleKey (SDL3)    │   ← 50Hz 轮询，变化时触发
└──────────┬───────────┘
           │  Qt 信号
           ▼
┌──────────────────────┐
│     MainWindow       │   ← 汇总输入快照
│  - Space/L3+R3 急停  │
│  - 汇总与新令牌重新采样    │
└──────────┬───────────┘
           │
           ▼
┌──────────────────────┐
│     Controller       │   ← 业务逻辑层
└──────────┬───────────┘
           │
           ▼
┌──────────────────────┐
│   RobotTcpClient      │   ← ControlSession v2过滤/授权/发送
│   Port 9090          │
└──────────┬───────────┘
           │
           ▼
┌──────────────────────┐
│  Intel NUC (下位机)   │   ← ROS2 执行控制
└──────────────────────┘
```

## 五、UI 显示

### 手柄状态面板 (`GamepadDisplayWidget`)

- **左右摇杆圆盘**：实时显示摇杆位置（圆点跟随移动）
- **LT/RT 扳机进度条**：竖直进度条显示扳机按压深度
- **按钮状态标签**：显示当前按下的按钮名称
- **连接状态**：绿色「已连接」/ 红色「未连接」

### 状态栏信息

- 控制模式显示：来自下位机状态或协议兼容字段
- 手柄连接状态
- 命令日志（带 500ms 节流防刷屏）
